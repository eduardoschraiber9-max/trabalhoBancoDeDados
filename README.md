# Trabalho Banco De Dados

## Como executar?

### 1 - Clonar o repositório na sua maquina

- Execute o comando no terminal:

      git clone https://github.com/eduardoschraiber9-max/trabalhoBancoDeDados.git 

### 2 - Instalar o banco de dados na sua maquina

- Acesse a pasta src\main\java\com\trabalho\ConexaoBanco.java e veja se a senha root coincide com a senha root sua.
  
- Execute o comando no terminal:

      mysql -u root -p sigpesq                                                   

- Agora, teste a conexão com o banco de dados executando apenas o arquivo ConexaoBanco.java
  
### 3 - Executar o código
- Agora, execute o comando no terminal:
  
      mvn javafx:run
